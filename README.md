# 🍣 Kamakura Food - Pedidos Online

## 📓 Briefing del Proyecto
Kamakura Food es una plataforma web de e-commerce diseñada para un restaurante de comida japonesa con el objetivo de permitir a sus clientes realizar pedidos online de forma ágil e intuitiva. 

Este proyecto simula un entorno de desarrollo real donde la estructura base (HTML5) y los estilos visuales (CSS3) han sido proporcionados por la empresa. Mi labor ha consistido en desarrollar de forma individual toda la lógica de programación y la interactividad del sitio utilizando JavaScript.

---

## 🚀 Explicación del Proyecto y Funcionalidades
La aplicación ha sido desarrollada siguiendo los requisitos funcionales establecidos y resuelve tres áreas clave:

1. **Menú Dinámico y Filtros:** Impresión automatizada en pantalla de los platos y las categorías a partir de los datos origen, permitiendo al usuario filtrar el menú en tiempo real.
2. **Gestión del Carrito de Compras:** Un menú lateral interactivo que permite añadir productos, controlar de forma estricta que no se dupliquen las líneas de pedido, y modificar las cantidades (incrementar/decrementar) actualizando los subtotales automáticamente.
3. **Cierre de Compra:** Generación y visualización de un recibo final detallado con el desglose de los platos escogidos, sus cantidades y el cálculo del total general de la compra.

---

## 🛠️ Tecnologías y Herramientas
El desarrollo se ha regido estrictamente por los requisitos técnicos de calidad exigidos:

* **HTML5 y CSS3:** Estructura y diseño base provistos por la empresa (sin alteraciones en clases o identificadores originales).
* **JavaScript (ES6+):** Programación funcional utilizando métodos nativos (`forEach`, `filter`).
* **Sintaxis Moderna:** Uso exclusivo de *Template Strings* para la manipulación del DOM.
* **Arquitectura:** Organización del código basada en módulos nativos (`ESModules`).
* **Entorno de Desarrollo:** Visual Studio Code, Git y GitHub para el control de versiones.

## 🗓️ Planificación Temporal
El proyecto se ha llevado a cabo bajo el marco de metodologías ágiles estructurado en **1 Sprint** de trabajo enfocado, dividiendo el desarrollo en las siguientes fases:
* **Fase 1:** Conexión de datos de origen (`data.js`) e impresión dinámica del menú y filtros en el DOM.
* **Fase 2:** Lógica de apertura/cierre del menú lateral y captura de eventos para añadir productos.
* **Fase 3:** Desarrollo de la lógica del carrito (control de duplicados, contadores y borrado automático al llegar a 0).
* **Fase 4:** Pantalla de pago y desglose del recibo final.
